# Inference dependencies — heavy, needed only for the ML endpoints.
# The plain API (auth, CRUD, dashboard) runs on base.txt alone.
#
# The trained image detector is a KERAS 3 artefact (best_model.keras,
# MobileNetV2). Keras 3 is backend-agnostic — it can execute on TensorFlow,
# JAX, or PyTorch. This project's Python is 3.14, and `tensorflow` has no
# published wheel for it yet (confirmed: `pip install tensorflow-cpu` fails
# with "no matching distribution", not a slow/blocked install — there is
# nothing to wait out). Rather than block Image on a TensorFlow release with
# no announced date, `image_detector.py` sets KERAS_BACKEND=torch and runs
# Keras on top of the PyTorch install that Audio/Video/Text already require.
# No `tensorflow` install is needed at all as a result.

-r base.txt
